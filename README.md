# 太子伴读

> 写下此刻的一点点。

一个极简的社交信息流应用，纯粹的书写角落：打开页面，写下 140 字以内的片段，它会以卡片形式落进下方的时间线，并安静地保存在这台设备上。

**零依赖、零构建** —— 只有一个 `index.html`，双击即可运行。

## 功能清单

| 功能 | 说明 |
| --- | --- |
| 发布 | 顶部多行输入框，上限 140 字；按码点计数，中文与 emoji 都不会被算成多个字 |
| 实时字数 | 实时显示「还可输入 N 字」，剩余 ≤ 20 字转琥珀色，超出后变红并抖动提示，发布按钮自动禁用 |
| 时间线 | 新帖永远排在最前；显示正文与相对时间（刚刚 / N 分钟前 / N 小时前 / N 天前 / 具体日期），每 30 秒自动校准 |
| 删除 | 每条卡片右上角删除入口，触发二次确认弹窗；确认后卡片淡出再移除 |
| 空状态 | 没有内容时展示内联 SVG 插画与引导文案 |
| 持久化 | localStorage 存储，刷新、关闭浏览器后数据仍在 |
| 微交互 | 按钮 hover 变色、发布 loading 态、新帖淡入上浮、卡片 hover 抬升、弹窗缩放淡入 |
| 响应式 | 容器最大宽度 600px 居中；窄屏下内边距收窄、按钮整行、删除入口常显 |
| 无障碍 | `aria-live` 字数播报、`role="dialog"` 弹窗、Esc 关闭、焦点自动归位、遵循「减少动态效果」偏好 |

## 本地运行

方式一（最简单）：直接双击 `index.html`，用浏览器打开即可。

方式二（推荐，带本地服务）：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```

```bash
# 或者 Node.js
npx serve .
```

建议使用 Chrome / Edge / Firefox / Safari 的较新版本。

## 技术说明

- **技术栈**：原生 HTML5 + CSS3 + ES6+ JavaScript，无框架、无构建工具、无外部依赖
- **存储结构**（localStorage 键名 `taizi.feed.v1`，带版本号便于升级）：

```json
{
  "version": 1,
  "posts": [
    {
      "id": "c6744657-18cf-499b-889d-b5dc657372a9",
      "content": "窗外的梧桐叶全黄了，风一吹像有人在翻书。",
      "createdAt": 1794533206827,
      "author": { "name": "我" },
      "stats": { "likes": 0, "replies": 0 }
    }
  ]
}
```

`author` 与 `stats` 是为后续扩展（昵称、点赞、回复）预留的字段，读取时会做兜底校验。

- **XSS 防护**：用户输入一律通过 `textContent` 写入 DOM，绝不参与 `innerHTML` 拼接；仅固定不变的图标与骨架使用模板字符串。
- **渲染策略**：首屏用 `DocumentFragment` 批量插入；发布时增量 `prepend`，不重建整个列表；相对时间只更新 `time` 节点的文案。

## 数据说明

所有内容仅保存在当前浏览器的 localStorage 中，不会上传到任何服务器；清除浏览器站点数据或更换设备后将无法找回。无痕模式下 storage 不可用时，应用会降级为内存态并给出提示。
