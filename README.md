一个纯前端的轻量级动态广场：打开页面，写下 140 字以内的片语，它会带着自己的一抹颜色落进信息流，并安静地保存在这台设备上。

**零依赖、零构建** —— 只是一个 `index.html`，双击即可运行。

## 功能清单

| 功能 | 说明 |
| --- | --- |
| 发布 | 多行输入框，上限 140 字；按 Unicode 码点计数，中文与 emoji 都不会被算成多个字 |
| 实时字数 | 进度条 + 「还可输入 N 字」；剩余 ≤ 20 字转琥珀色，超出变红并禁用发布 |
| 查看详情 | 每张卡片右下角的立体「查看」按钮，弹出详情面板：全文、字数、获赞、发布日期 |
| 点赞 | 卡片与详情面板都可点赞，爱心有弹跳反馈，数据写入本地 |
| 删除 | 详情面板内删除，触发二次确认；确认后卡片淡出再移除 |
| 搜索 | 顶部搜索框实时过滤正文；点击正文里的 #话题 或右侧热议榜也能直接搜索 |
| 排序 | 「全部」按时间倒序，「热门」按获赞排序 |
| 热议榜 | 从所有片语里的 #话题 自动统计条数，不足 5 条时用默认话题补齐 |
| 示例数据 | 首次打开写入 3 条示例片语，方便直接体验查看 / 点赞 |
| 持久化 | localStorage 存储，刷新、关闭浏览器后数据仍在；多标签页通过 `storage` 事件同步 |
| 响应式 | 桌面三栏（我的 / 信息流 / 热议），平板两栏，移动端单栏 + 吸底导航 |
| 无障碍 | `aria-live` 字数播报、`role="dialog"` 弹层、Esc 关闭、焦点归位、遵循「减少动态效果」偏好 |

## 视觉与动效

- **配色**：粉 `#FF3D9D` → 紫 `#A855F7` → 蓝 `#6366F1` → 青 `#22D3EE` 的多色渐变体系；背景是四团缓慢漂浮的彩色极光。
- **3D 按钮**：通过 `inset` 高光、底部硬边阴影与彩色投影叠出厚度；悬停抬升 2px、按下回弹 4px，配合扫过式高光。
- **主发布按钮**：`发布` 按钮叠加粉紫蓝青流动渐变、旋转光晕与呼吸位移；未输入时自动降为柔和浅彩。
- **卡片色彩**：每条片语从调色板取一个色相，头像、左侧色条、详情页封面共用同一色相，形成"一人一色"。
- **动效**：新片语淡入上浮、点赞爱心弹跳、弹窗缩放进入、顶部彩虹细线持续流动。

## 本地运行

方式一（最简单）：直接双击 `index.html`，用浏览器打开即可。

方式二（推荐，带本地服务）：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```

```bash
# 或者 Node.js
npx serve .
```

建议使用 Chrome / Edge / Firefox / Safari 的较新版本。

## 技术说明

- **技术栈**：原生 HTML5 + CSS3 + ES6+ JavaScript，无框架、无构建工具、无外部依赖、无网络请求
- **存储结构**（localStorage 键名 `taizi.feed.v2`，带版本号便于升级）：

```json
{
  "version": 2,
  "posts": [
    {
      "id": "c6744657-18cf-499b-889d-b5dc657372a9",
      "content": "窗外的梧桐叶全黄了，风一吹像有人在翻书。#今日片语",
      "createdAt": 1794533206827,
      "likes": 12,
      "liked": false,
      "hue": 340
    }
  ]
}
```

读取时对每个字段做校验与兜底：缺 `hue` 的老数据会用 FNV-1a 从 id 推导色相，空内容条目直接丢弃。

- **XSS 防护**：用户输入一律通过 `textContent` / `createTextNode` 写入 DOM，绝不参与 `innerHTML` 拼接；`innerHTML` 只用于固定不变的图标骨架。
- **渲染策略**：使用 `DocumentFragment` 批量插入；点赞时就地更新当前卡片，不重建列表；相对时间每 30 秒只刷新 `time` 节点文案。
- **降级**：隐私模式或存储配额不足时，发布与点赞仍可在当前页面生效，并通过轻提示告知"仅保留在本次会话"。

## 数据说明
